## 🚀 시작하기

### 1. 로컬에서 열기
1. `index.html` 파일을 브라우저에서 열기
2. 업무 등록 버튼 클릭해서 데이터 추가
3. 데이터는 브라우저 localStorage에 자동 저장됨

### 2. GitHub Pages에서 배포 (archlaw-manager.store)
1. GitHub 저장소에 파일 업로드
2. Settings → Pages → Deploy from a branch 설정
3. 도메인 DNS 레코드 설정
4. `archlaw-manager.store`에서 접속

## 📝 사용 방법

### 업무 등록
1. **+ 업무 등록** 클릭
2. 구분 선택 (법령/공문)
3. 기본 정보 입력
   - 제목/법령명
   - 공포/접수일
   - 시행/회신기한
   - 담당/발송처
   - 해야 할 일
4. **v0.4 신규**: 의견조회/법령 분류/우선순위 선택 (선택사항)
5. 저장

### 상태 관리
- **진행중**: 작업 중
- **회신대기**: 회신 대기 중
- **완료**: 완료됨

### 검색 & 필터
- 검색창: 제목, 법령명, 발송처, 메모로 검색
- 상태 필터: 진행중/회신대기/완료 선택
- 구분 필터: 법령/공문 선택
- 탭: 전체/법령/공문/의견조회/상태별 보기

### 엑셀 일괄등록
1. 엑셀 파일 준비 (권장 열 참고)
2. **엑셀 일괄등록** 클릭
3. 미리보기 확인 후 등록

**권장 열:**
```
구분, 제목/법령명, 공포번호/문서번호, 공포일/접수일, 시행일/회신기한, 
담당/발송처, 해야 할 일, 주요내용/메모, 상태
```

### 백업
- **백업 내보내기**: JSON 파일로 다운로드
- **백업 불러오기**: 이전 백업 복구

### 저장 위치
- **로컬**: 브라우저 localStorage (`archlaw_data_v0.4`)
- **나중에** (v0.7+): Supabase PostgreSQL DB로 이전 예정

### v0.2 → v0.4 자동 마이그레이션
- v0.2 데이터 로드 시 자동으로 v0.4 스키마로 변환
- 기존 필드는 100% 유지
- 신규 필드는 null/빈값으로 채워짐
- **기존 데이터 손실 없음** ✓

## 🐛 문제 해결

### "엑셀을 읽을 수 없습니다" 오류
→ 첫 번째 행에 열 제목이 있는지 확인

### 데이터가 저장되지 않음
→ 브라우저 localStorage 용량 확인 (PC 기준 5~10MB)

### 다른 브라우저/PC에서 데이터가 안 보임
→ 정상입니다. localStorage는 브라우저별 독립적입니다.  
→ 백업 내보내기로 JSON 다운로드 → 다른 기기에서 불러오기
